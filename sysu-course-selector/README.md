# SYSU Course Selector

中山大学教务系统选课辅助工具。当前版本提供图形界面和命令行界面，支持专业选修、公共必修与体育课查询、预选体育志愿、自动抢选、选课结果查询和退课。

> 请遵守学校的选课规定与教务系统使用规则。工具只是按你的操作发送请求，不能保证选课成功。

## 安装

1. 安装 Python 3.8 或更高版本（推荐 Python 3.12）。
2. 在项目目录安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

## 图形界面（推荐）

启动：

```bash
python main.py
```

1. 输入 NetID 与密码并登录。密码仅用于本次会话，不会写入文件。
2. 程序会自动加载专业选修、公共必修、体育三类可选课程；它们分别显示在“可选课程”页的独立标签中。
3. 每行都显示课程号、教学班号、课程名称、上课信息、容量和状态。预选阶段还会显示“待筛选人数”。
4. 选中一个或多个教学班，点击“加入选中教学班”，再点击“开始选课”。也可手动填写教学班号或教学班 ID（用英文逗号分隔）。
5. “自动抢课运行监视”窗口会显示请求、人数已满重试、系统限制、停止和成功状态；抢选成功会弹出通知。
6. “选课结果”页可查看已选成功、已选失败、已选待筛选课程。选中成功或待筛选课程后，可使用“退选当前选中课程”。退课前会要求确认。

### 教学班号与体育课

选课接口实际按教学班 ID 提交；教学班号是便于识别的短编号。课程号本身可能不唯一，例如多门体育课可共用 `PE305`。因此，程序会拒绝把一个对应多个教学班的课程号直接用于选课，请使用教学班号或教学班 ID。

手动输入教学班号时，程序会直接从教务接口解析对应的教学班 ID，并发送选课请求，不受当前界面列表限制。若只掌握内部教学班 ID、且该课程无法被列表解析，可用 `教学班ID@选课类型@选课类别` 直接提交；例如体育为 `2072220589400616960@3@10`，公共必修通常为 `ID@1@10`，专业选修通常为 `ID@1@21`。这会直接把请求交给教务系统，是否成功仍由教务系统的容量、时间冲突和选课规则决定。


### 体育预选志愿

程序会自动读取教务系统的选课阶段。

- **预选阶段**：体育最多可保留 4 个志愿。体育课程提交一次即可，不进行持续抢选；随后在“体育志愿（仅预选阶段）”页上移／下移并保存第一至第四志愿。
- **抢选阶段**：不显示志愿排序，体育课按普通课程持续抢选。

### 停止抢选与失败提示

点击“停止选课”后，正在执行的网络请求结束即不再重试。

- **人数已满**：保留自动监视并按设置的间隔重试。
- **课程时间、考试时间或跨校区时间冲突**：停止该教学班的无效重试。
- **学分／课程数上限、选课范围、未注册、未评教、欠费等系统限制**：停止该教学班的无效重试。

登录区可设置并发请求数、重试间隔、网络超时，以及本机 SOCKS5 代理端口。请避免设置过高并发或过短重试间隔。

## 命令行界面

如需使用命令行，创建本地 `info.py`：

```python
name = '你的 NetID'
pwd = '你的密码'
```

随后运行：

```bash
python cli.py
```

CLI 登录后同样会自动加载并按类别输出全部可选课程。持续抢选时按 `Ctrl+C` 会发送停止指令；体育预选阶段会显示当前志愿并提示输入完整排序。



## 当前接口

本版本使用 CAS v3 登录流程：获取登录策略和公钥、加密密码、完成 JWXT 学生 SSO，并自动读取当前选课学期与选课阶段。

## 2FA的注意事项
鉴于一次2FA验证的时效性比较长，我并没有做通过2FA的登录。（实际上我懒得一次次清除标志、所以我也没得到样本数据。）如果遇到2FA问题，自己在浏览器登录一遍通过2FA认证即可在相当长的一段时间使用本工具。
