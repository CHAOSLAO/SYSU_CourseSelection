# SYSU Course Selector

中山大学教务系统选课辅助工具，提供图形界面和命令行界面，支持专业选修、公共必修与体育课查询、体育预选志愿、自动抢选、选课结果查询和退课。

> 请遵守学校的选课规定与教务系统使用规则。工具只会按你的操作发送请求，不能保证选课成功，也不会绕过学校的访问控制或选课限制。

## 安装与启动

1. 安装 Python 3.8 或更高版本（推荐 Python 3.12）。
2. 在项目目录安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

3. 在 Windows 中双击 [run.bat](run.bat) 即可启动图形界面。脚本会优先使用 Python Launcher（`py -3`），未检测到时再尝试 `python`。

也可以手动启动：

```bash
python main.py
```

## 图形界面（推荐）

使用流程：

1. 先选择当前处于“预选阶段”或“抢选阶段”，再输入 NetID 与密码登录。程序会与服务器返回的阶段信息核对；不一致时不会开始选课。
2. 登录后自动加载专业选修（`1/21`）、公共必修（`1/10`）和体育（`3/10`）三个类别的可选课程。
3. 在课程表中勾选目标课程。同一课程号的体育课会同时显示教学班号、班级号、教师及时间地点，避免混淆。
4. 点击“开始选课”即可自动执行；也可手工填写教学班号或内部教学班 ID。
5. “自动抢课运行监视”会显示轮询、成功、失败、待筛选与体育换课状态；成功时会弹出通知。
6. “选课结果”可查看已选成功、已选失败和已选待筛选课程，并可退掉当前选中的成功或待筛选课程。
7. “重新登录（当前账号）”会用本次运行内存中的账号重新建立会话；“切换账号”会清除内存账号；“退出”会先停止选课线程。

界面只显示当前阶段适用的体育功能：预选阶段显示四个体育志愿，抢选阶段显示体育自动换课说明。

### CAS 人工协助登录

当 CAS 在密码验证后要求二次验证时，程序会保留本次临时 CAS 会话，并显示“CAS 人工协助验证”区域。若 CAS 提供“企业微信验证码”，可按以下步骤继续：

1. 点击“发送企微验证码”；
2. 在本人已绑定的企业微信中查看验证码；
3. 将验证码输入程序，点击“验证并继续登录”。

程序只向 CAS 请求验证码并提交你输入的验证码，验证成功后自动继续 JWXT SSO 和课程加载。它不会读取企业微信内容、代替确认，也不会绕过 CAS MFA。若 CAS 仅提供企业微信网页登录或其他方式，请在官方 CAS 页面完成验证后重新登录。

该流程已使用实际 CAS MFA 会话验证。企业微信验证码在当前 CAS 配置中为 4 位；程序会按 CAS 风险验证页面要求，通过专用验证通道连同当前应用标识提交验证码，而不是把它当作普通账号密码登录请求。

## 教学班号、教学班 ID 与体育课

选课接口按内部教学班 ID 提交；教学班号是便于识别的短编号。课程号本身可能不唯一，例如多门体育课可共用 `PE305`。因此，程序要求按教学班号或内部教学班 ID 区分课程，并在界面中显示班级、教师和上课信息。

手动输入教学班号时，程序会尝试从教务接口解析对应的教学班 ID，不受当前界面列表限制。若只掌握内部教学班 ID 且课程无法被列表解析，可填写：

```text
教学班ID@选课类型@选课类别
```

例如体育通常为 `ID@3@10`，公共必修通常为 `ID@1@10`，专业选修通常为 `ID@1@21`。这只会直接向教务系统提交请求；容量、时间冲突、年级范围、培养方案和其他选课规则仍由服务器判定。

对于不在个人可选课列表中的课程，可用学校公开开课目录按学期、课程号和教学班号查询。目录返回的 `class_ID` 经已知课程比对后与选课接口所用的内部教学班 ID 一致；它不是课程 ID，也不是课程集合 ID。该查询只能帮助定位公开的教学班标识，不能突破选课范围、资格或容量限制。

## 体育课与阶段功能

启动时由用户选择阶段，登录后再由服务器校验：

- **预选阶段**：体育课最多可填 4 个志愿，按“志愿 1 → 志愿 4”的顺序提交；同一教学班号不能重复。课程表会显示待筛选人数。
- **抢选阶段**：不显示志愿排序。若已选体育课正是目标教学班，体育任务自动结束；否则程序持续扫描所勾选体育班的余量，发现空位后会先退掉当前体育课，再立即尝试选择目标班。

抢选阶段的体育换课会按用户选择直接执行，不保留原体育课；退课后目标班仍可能被他人抢先选满。

## 停止、失败提示与退课

点击“停止选课”后，正在执行的网络请求结束即不再重试。

- **人数已满**：继续按设置的间隔监视并重试。
- **课程时间、考试时间或跨校区时间冲突**：停止该教学班的无效重试。
- **学分/课程数上限、选课范围、未注册、未评教、欠费等系统限制**：停止该教学班的无效重试。

登录区可设置并发请求数、重试间隔、网络超时及本机 SOCKS5 代理端口。请避免设置过高并发或过短重试间隔。

## 命令行界面

如需使用命令行，请在本地创建 `info.py`（仓库中的文件只应保留占位符）：

```python
name = '你的 NetID'
pwd = '你的密码'
```

随后运行：

```bash
python cli.py
```

CLI 会先提示选择预选或抢选阶段，登录后会校验服务器阶段、加载并按类别输出课程。若 CAS 要求二次验证且提供企业微信验证码，CLI 会询问是否发送验证码并提示输入；体育预选阶段会提示输入最多 4 个志愿；抢选阶段的体育目标按自动换课逻辑处理。持续抢选时按 `Ctrl+C` 可停止。

## 当前接口

本版本使用 CAS v3 登录流程：获取登录策略和公钥、加密密码、完成 JWXT 学生 SSO，并读取当前选课学期与选课阶段。

## 二次验证（2FA）

如 CAS 要求二次验证，请先在学校官方页面或浏览器中完成验证，再重新登录本工具。工具不处理、也不会尝试绕过二次验证或其他学校的访问控制。
