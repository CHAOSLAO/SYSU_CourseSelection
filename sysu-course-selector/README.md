# 中山大学(SYSU)选课系统的抢课软件

## 这是什么？

SYSU Course Selector(SCS)，是一个基于 python3 的抢课软件，系我在贵校就读三年来，从未选上理想的课程，愤然而作。

实践证明，有了 SCS 的帮助，我的确选到了我想要的课程。

## 如何使用？

0. 你必须把源码拉到本地，执行 `git clone https://github.com/Siriussee/sysu-course-selector.git`；
1. 我只提供了源代码，所以首先你得准备一个 [Python 3.8+](https://www.python.org/downloads/)（推荐 Python 3.12）；
2. 安装对应的依赖 `pip install -r requirements.txt`；
3. 运行主程序 `python main.py`；
4. 在图形界面中输入 NetID 和密码（密码只用于本次登录，不会保存）；
5. 勾选课程范围，查询后在列表中选中教学班并加入目标列表，或填写教学班号／教学班 ID；体育课等同课程号的不同课程必须用教学班号区分；
6. 在“选课结果”页面可随时刷新并查看已选成功、已选失败与已选待筛选课程。持续选课期间请保持程序运行。

体育课处于“预选”阶段时，最多可提交 4 个志愿。GUI 请在“体育志愿”页使用上移／下移并保存第一至第四志愿；CLI 会在选课后提示输入完整的志愿顺序。进入抢选阶段后，程序会自动关闭志愿排序，体育课按普通持续抢选处理。

如需使用旧的命令行界面，先根据实际情况填写本地 `info.py`，再执行 `python cli.py`。

查询范围可输入多个编号：`1` 为专业选修，`2` 为公共必修，`3` 为体育。例如输入 `2,3` 会同时查询公共必修和体育；后续选课时程序会为每个教学班自动使用对应的类别标识。

当前版本使用 CAS v3 登录接口：程序会获取 CAS 公钥、加密密码，再通过 JWXT 的学生 SSO 地址创建选课会话。若学校要求额外身份验证，请先在浏览器完成验证后再重试。

需要注意的是，这个抢课软件也仅仅是在有人退课的情况下为你尽快抢选这门课程。因此，它不能保证你一定能够选上这门课——说不定大家都不退课，或者有别人也用了这个软件捷足先登了呢。

## 更新日志 / Changelog

### 2026-07-15
- **图形化界面**：`python main.py` 现启动完整交互界面，可在同一窗口中登录、配置并发／超时／代理、查询专业选修／公共必修／体育课程、持续选课，并查看选课结果。
- **分类与运行监视**：可选课程按专业选修、公共必修、体育分类显示；GUI 新增“自动抢课运行监视”窗口，实时显示请求、重试与成功状态，并在成功时弹出通知。
- **预选待筛选人数**：预选阶段的课程列表展示教务系统返回的“待筛选人数”，便于比较每个教学班的筛选压力；非预选阶段显示为“—”。
- **教学班精确选课**：列表显示教学班号，可多选后加入目标列表。选课接口实际使用教学班 ID；当一个课程号对应多个教学班（如体育课 `PE305`）时，程序会拒绝只填课程号，防止误选多个班。
- **体育预选志愿**：根据教务系统当前阶段自动启用体育志愿。预选阶段限制为 4 个体育志愿，支持查询、显示、上移／下移和保存第一至第四志愿；抢选阶段自动禁用志愿排序。
- **选课结果查询**：增加“已选成功”“已选失败”“已选待筛选”三个结果页，直接使用教务系统的结果状态查询，不以抢课请求是否发出作为成功依据。
- **命令行保留**：如需继续使用旧式终端交互，可执行 `python cli.py`；其中仍从本地 `info.py` 读取账号信息。
- **认证接口升级**：改用 CAS v3 的策略、公钥和登录接口，以及 JWXT 学生 SSO 登录地址。
- **选课接口修正**：使用当前 JWXT 域名请求头和接口路径，并从 `selectCourseInfo` 自动获取当前选课学期，不再固定使用 `2018-2`。
- **错误提示改进**：登录、会话初始化和课程号不匹配时提供可读错误信息。
- **选课范围扩展**：支持公共必修（`type=1, cate=10`）和体育（`type=3, cate=10`），并可组合查询。
